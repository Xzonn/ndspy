``ndspy.lz11``: LZ11 Compression
================================

.. py:module:: ndspy.lz11

``ndspy.lz11`` provides functions for compression and decompression in the
LZ11 format used in Nintendo DS and Nintendo 3DS software.

.. py:function:: compress(data)

    Compress a :class:`bytes` object using LZ11 and return the compressed
    :class:`bytes` object.

.. py:function:: decompress(data)

    Decompress an LZ11-compressed :class:`bytes` object and return the
    decompressed :class:`bytes` object.

.. py:function:: compressFromFile(filePath)

    Read a file, compress its contents using LZ11, and return the compressed
    :class:`bytes` object.

.. py:function:: compressToFile(data, filePath)

    Compress a :class:`bytes` object using LZ11 and write it to a file.

.. py:function:: decompressFromFile(filePath)

    Read an LZ11-compressed file and return the decompressed :class:`bytes`
    object.

.. py:function:: decompressToFile(data, filePath)

    Decompress an LZ11-compressed :class:`bytes` object and write it to a file.

.. py:function:: main(args=None)

    Run the :doc:`command-line interface <../cli/lz11>`.
