``ndspy.lz11``: LZ11 Compression
================================

The ``ndspy.lz11`` command-line interface compresses and decompresses files in
the LZ11 format.

Run it using ``python3 -m ndspy.lz11`` or ``ndspy_lz11``. It accepts
``compress`` (``c``) and ``decompress`` (``d``) commands, followed by an input
file and an optional output file.
